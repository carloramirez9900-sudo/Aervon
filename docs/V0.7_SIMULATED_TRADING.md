# v0.7 — Simulated Trading Cycle Engine

## Scope
- One global 24-hour cycle (UTC day).
- Exactly 5 simulated unified trades per cycle.
- One global target yield rate per cycle, generated inside the configured 3.5%–5% range.
- The 5 simulated PnL slices reconcile exactly to the target yield using Decimal arithmetic.
- Trades are scheduled across the full 24-hour window with varied open/close times.
- Public Binance ticker prices are captured as market references at simulated open/close.
- The simulated exit price is calculated from the target PnL allocation; it is not represented internally as an exchange fill.
- `executionMode=SIMULATED` is persisted and exposed by the API.
- No platform-wide capital total or user-count metrics are implemented in this phase.

## API
- `GET /trading/current` — current cycle, participation, progress and trades.
- `GET /trading/history?limit=50` — recent closed simulated trades.

Both endpoints require the existing Bearer access token.

## Scheduler
`CycleOrchestratorService` runs every minute. It creates/starts the UTC-day cycle, plans the 5 trades, advances due trades, and settles the cycle at the end of the window.

## Important representation rule
The simulated trade history is not an exchange execution record. Market prices are reference observations only. The API always returns a simulation disclosure and each trade carries `executionMode=SIMULATED`.
