# v0.8 — Five trades per cycle + per-user USDT PnL

- Every global cycle lasts 24 hours and contains exactly 5 simulated unified trades.
- The configured cycle yield remains global and is reconciled exactly across those 5 trades.
- Each user sees the same trade PnL rate but an individualized `pnlUsdt` calculated from the principal captured in that user's cycle participation.
- Formula: `pnlUsdt = principalAtCycle * pnlRate`.
- `GET /trading/current` now exposes `accumulatedPnlUsdt` and `pnlUsdt` per trade when the user participates in the cycle.
- `GET /trading/history` returns only closed trades from cycles in which the authenticated user participated, with `pnlRate`, `pnlUsdt`, and `principalAtCycle`.
- Global capital and total-user metrics remain intentionally absent from this phase.
- Execution remains explicitly `SIMULATED`; no exchange order is created.
