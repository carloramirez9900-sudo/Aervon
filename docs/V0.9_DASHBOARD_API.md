# v0.9 Dashboard API

## Endpoint

`GET /dashboard`

Requires `Authorization: Bearer <access-token>`.

The endpoint is user-scoped. It never returns global platform capital or global user counts.

## Response areas

- `wallet.totalBalance`: sum of user available, active principal, pending compound and withdrawal-pending balances.
- `wallet.availableBalance`: funds currently available to use or withdraw.
- `wallet.activePrincipal`: principal currently assigned to trading cycles.
- `wallet.pendingCompound`: amount queued to be added to principal on the next eligible cycle.
- `wallet.withdrawalPending`: funds reserved by pending withdrawals.
- `earnings.totalYieldEarned`: lifetime settled cycle profits.
- `earnings.totalReferralEarned`: lifetime direct-referral commissions.
- `investment`: state and 10-cycle principal lock progress.
- `currentCycle`: current global 24h cycle, progress across 5 trades, user accumulated PnL in rate and USDT, and all 5 trade records.
- `recentTrades`: recent CLOSED trades from cycles in which this user participated, each with `pnlRate` and user-specific `pnlUsdt`.

## Important semantics

`availableBalance` is not labeled as profit because it can contain uninvested deposits, cycle profits, referral commissions, or released principal.

The API explicitly returns:

```json
{
  "visibility": {
    "showPlatformCapital": false,
    "showPlatformUserCount": false
  }
}
```

The trading records are simulated trading activity and are not exchange executions.
