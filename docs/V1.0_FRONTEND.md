# AERVON Frontend v1.0

Mobile-first React/Vite frontend for AERVON.

## Implemented screens

- Login with country flag/calling-code selector and password visibility toggle.
- Registration: phone/referral -> Telegram verification -> password creation.
- Dashboard connected to `GET /dashboard`.
- Dashboard visualizes total/available/active balances, earnings, current cycle, 5 trades, user-specific PnL in percent + USDT, principal 10-cycle progress, and recent closes.
- Loading, empty and error states.
- Mobile-first dark premium visual system inspired by the supplied reference but with an original AERVON identity.

## Transparency

Trading UI uses the backend's simulated unified trading data. It does not claim exchange execution. A disclosure is shown on the dashboard.

## Run

Backend:

```bash
npm install
npm run start:dev
```

Frontend:

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Default frontend API URL: `http://localhost:3000`.

Backend CORS now accepts `FRONTEND_ORIGINS` (comma-separated), defaulting to `http://localhost:5173`.

## Security note

The current backend returns refresh tokens in JSON. The frontend stores the auth session only in `sessionStorage` (not localStorage), so it disappears when the browser session closes. Before public production, move refresh tokens to Secure, HttpOnly, SameSite cookies or an equivalent BFF/session pattern.
