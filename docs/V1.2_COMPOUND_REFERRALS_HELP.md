# AERVON v1.2 — Compound, referrals and help center

## Scope

This release adds the next user-facing block while keeping the mobile-first visual system introduced in v1.0/v1.1.

### Compound interest

Authenticated endpoints:

- `GET /investments/me`
- `POST /investments/compound` with `Idempotency-Key`
- `PATCH /investments/compound-mode`
- `POST /investments/activate` with `Idempotency-Key`
- `POST /investments/stop` with `Idempotency-Key`

The compound page lets a user choose `MANUAL` or `AUTOMATIC`, see available/active/pending balances, and schedule manual reinvestment for the next eligible cycle. Pending compound is never injected into a cycle already in progress.

### Referrals

Authenticated endpoint:

- `GET /referrals/summary`

The API returns the user's code, configured commission percentage, direct/active counts, all-time total commission, masked referred-user identifiers and recent commission history. The commission remains one direct level and is calculated from the referred user's eligible cycle profit.

The frontend generates a shareable URL in the form `/register?ref=CODE`; registration now pre-fills that code automatically.

### Help center

The help center is a permanent in-app resource rather than a mandatory onboarding gate. It documents AERVON, unified cycles, simulated trading activity, PnL, compound, BEP-20 deposits, withdrawals, referrals and account security.

The trading explanation explicitly states that the unified activity is simulated/contextualized with market references and does not claim exchange execution.
