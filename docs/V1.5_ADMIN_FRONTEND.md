# AERVON v1.5 — Administration frontend

## Routes

- `/admin` — operational dashboard
- `/admin/users` — user search, detail, status and audited balance adjustments
- `/admin/finance` — deposits and withdrawals, including security hold/release/cancel actions
- `/admin/operations` — cycles, investments and referral summary
- `/admin/settings` — runtime pause controls and read-only financial rules
- `/admin/audit` — administrative audit log

All routes are protected by the normal authenticated session and an additional `GET /admin/me` authorization check. The backend remains the source of truth for RBAC.

## Responsive design

The admin area is responsive but intentionally different from the customer interface. Mobile uses a compact fixed navigation; desktop/tablet uses a persistent sidebar and wider operational tables.

## Money safety

The frontend does not expose a direct balance editor. Adjustments call the backend `ADMIN_ADJUSTMENT` endpoint and require amount, direction, reason and an idempotency key. Withdrawal controls call audited backend operations only.

Private keys, mnemonic, JWT secrets and Telegram credentials are never requested or rendered by this frontend.
