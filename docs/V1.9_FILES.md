# v1.9 changed files

- `src/deposits/wallet-derivation.service.ts`: XPUB-only derivation.
- `src/deposits/deposit-sweep.service.ts`: restricted external signing, MongoDB per-address lease, immutable batches, durable signed tx, safe recovery, matching Transfer confirmation.
- `src/deposits/deposit-signing-client.service.ts`: HMAC-authenticated internal signer client and strict returned-tx validation.
- `src/deposits/deposits.module.ts`: signing-client registration.
- `src/database/schemas/deposit.schema.ts`: durable per-address sweep state.
- `signer/server.mjs`, `signer/validation.mjs`, `signer/validation.test.mjs`: standalone private signer and policy tests.
- `scripts/generate-deposit-hd.mjs`: LOCAL/OFFLINE-only new-seed + xpub generator; DO NOT USE if existing deposit addresses exist.
- `.env.railway.backend.example`, `.env.signer.example`, `railway.signer.toml`: service-specific configuration.
- `package.json`, `.gitignore`, `README.md`, `docs/DEPOSIT_ENGINE.md`, `docs/V1.7_DEPLOYMENT_PREP.md`, `docs/V1.9_ISOLATED_DEPOSIT_SIGNER.md`: commands, configuration, documentation.

No frontend changes were needed. The withdrawal hot-wallet signing and gas wallet are NOT migrated in this release.
